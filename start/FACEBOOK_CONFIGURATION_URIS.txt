6. ÉTAPES DE CONFIGURATION
========================================================

1. Aller sur : https://developers.facebook.com/apps/
2. Sélectionner votre application

   - Ajouter le domaine dans "App Domains"
   - Définir "Site Web URL"

4. Dans "Facebook Login" > "Settings" :
   - Ajouter les URIs OAuth

5. Dans "Webhooks" :
   - Définir l'URL de callback
   - Configurer le token de vérification

6. Dans "Instagram Basic Display" :
